
# 📊 Sales Analytics Dashboard

**An interactive Power BI report for exploring sales performance,
profitability, customers, products, and trends.**



## 🎯 Project Overview

A multi-page Power BI dashboard designed to make sales performance
easier to explore. It brings key metrics and interactive views together
so users can investigate products, customers, payment methods, cities,
order outcomes, and monthly trends.

## 🛠️ Tools & AI Workflow

-   **Power BI Desktop** --- report layout, visuals, filters, and KPI
    presentation.
-   **Power Query / DAX** --- common Power BI tools for preparing data
    and defining measures; verify the exact transformations and formulas
    in the PBIX.
-   **ChatGPT / AI** --- helped structure documentation, turn dashboard
    fields into business questions, and organize possible findings and
    recommendations.

AI-generated interpretations are starting points, not proof. Verify all
formulas, numeric results, and conclusions against Power BI and the
source dataset.

## 🚀 Open the Project

1.  Download or clone this repository.
2.  Open `Sales_Dashboard.pbix` in **Power BI Desktop**.
3.  Configure data-source access if prompted, then refresh the report.
4.  Explore the report pages and available slicers.
5.  Validate metric definitions and totals before using results for
    decisions.

## 💡 Business Questions

  **Performance**                     Which channels, categories, months,
                                      and sales reps lead?

  **Profitability**                   Which products sell well but have
                                      low margins?

  **Customers**                       How much sales value comes from top
                                      customers?

  **Payments**                        Do sales or margins differ by
                                      payment method?

  **Geography**                       Which cities and customer segments
                                      perform best?

  **Operations**                      What patterns appear in returns and
                                      order statuses?

  **Experience**                      How do customer ratings vary across
                                      categories or cities?

## 💡 Possible Actions

-   **Grow strategically:** Prioritize channels and segments with proven
    performance.
-   **Protect margins:** Review shipping costs, discounts, and
    low-margin products.
-   **Strengthen retention:** Investigate customer concentration and
    return patterns.
-   **Plan for demand:** Use repeatable monthly trends to inform
    campaigns and inventory.

Recommendations should be grounded in the data. Correlation alone does
not establish the cause of a trend.
